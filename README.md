# FRISDI
FRISDI is a hybrid AI-powered fraud risk intelligence platform that analyzes transaction behaviour, predicts fraud risk, explains suspicious signals, and allows users to simulate how changing transaction conditions affect risk. IT IS A MVP
# 🛡️ FRISDI

### Fraud Risk Intelligence & Detection Interface

FRISDI is a hybrid AI-powered fraud detection system that analyzes transaction data and predicts fraud risk.

It combines a **Random Forest machine-learning model** with **risk-based rules** to classify transactions as:

- 🟢 LOW RISK
- 🟡 MEDIUM RISK
- 🔴 HIGH RISK

---

## ✨ Features

- 🤖 AI-powered fraud risk prediction
- 🔍 Transaction risk explanations
- 🧠 Hybrid AI + rule-based risk engine
- ⚡ Live Risk Simulator
- 📊 Model performance metrics
- 🎯 Precision and recall evaluation
